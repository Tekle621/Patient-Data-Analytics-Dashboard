 # 🏥 Patient Data Analytics Dashboard | Power BI

An interactive healthcare analytics dashboard analyzing patient demographics, medical conditions, hospital visits, and treatment outcomes.

## 📌 Project Overview

This project uses a synthetic dataset of approximately 2,700 patients and 12,000 hospital visits to demonstrate healthcare data analytics and business intelligence using Microsoft Power BI.

## 📊 Dashboard Pages

1. Patient Summary – Patient demographics, regions, cities, age and primary diagnosis.
2. Age Group Distribution – Patient distribution by age, gender and diagnosis.
3. Visits Summary – Hospital visits by diagnosis and age group.
4. Age and Primary Diagnosis – Patient and hospital visit analysis.
5. Patient Treatment Plan – Medications, laboratory results and treatment information.

## 🔑 Key Metrics

- Total patients: 2.7K
- Total hospital visits: 12K
- Diabetes and hypertension analysis.
- Treatment outcome distribution.
- Insurance coverage.
- Average hospital visits per patient.

## 🛠️ Tools and Technologies

- Microsoft Power BI Desktop
- Power Query
- DAX
- Data Modeling
- Data Visualization
